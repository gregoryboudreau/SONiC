injectup:
    Injectup injects packets as if coming in from wire. Argument rx/rx_ifname specifies ingress interface name. Packet DST MAC is
        populated automatically if not specified. Note: the packet must be injected from the LC and NPU where the interface resides.
    If user packet doesn't have Ether header, the program will generate the header with src mac set to 00:00:00:00:00:01, dst
        mac as the ingress interface mac. This is not supported if user packet is specified in hex format.
    If user packet have Ether but not dst mac, ingress interface mac will be used. This is not supported if user packet is
        specified in hex format.
    If vlan id is provided, Dot1Q will be inserted after Ether header with the vlan ID. 
    Example 3 - inject IPv6 packets from fh0/0/0/0. DST MAC will be filled in automatically.

    Injectdown sends packets "directly" to an egress interface. The packets are still injected from rxpp but bypassing
        most of the logic then sent to the egress device.
        Argument tx/tx_ifname is the egress interface name.
        Argument s/inject_slice is the source slice in the local NPU where the packet will be injected.
    Example 5 - Sends packets as is from an egress interface with system port 304
        show controllers npu debugshell 0 'script tgen start -p Ether(dst=\"78:df:6e:36:90:08\",src=\"70:61:7b:98:47:00\")/IP(src=\"32.0.0.1\",dst=\"22.0.0.1\")/UDP()/Raw(loa
d=\"a\"*300) -r 100 injectdown -tx 304' location 0/0/CPU0

raw:
    In this mode, user needs to build Ethernet header, inject header followed by user packet.
    Example 6 - Inject raw packets from slice 2 IFG 1 of NPU 0
        show control npu debugshell 0 'script tgen start -f /misc/disk1/injectraw.pkt -r 100 raw -s 2 -i 1' location 0/0/CPU0
        Below is /misc/disk1/injectraw.pkt
            Ether(dst=PUNT_INJECT_PORT_MAC_ADDR, src=HOST_MAC_ADDR, type=Ethertype.Dot1Q.value) / \
            Dot1Q(prio=2, id=1, vlan=1, type=Ethertype.Inject.value) / \
            InjectUp(phb_tc=0, ssp_gid=8) / \
            Ether(dst='78:9c:9d:c0:9e:00', src='70:61:7b:98:47:00') / \
            IP(src="32.0.0.1", dst='22.0.0.1') / \
            UDP() / \
            Raw(load='a'*300)
